## **Power BI - Tool Images - Cheat Sheet**

#### **Power BI Tool** Session 1

Power BI is a powerful tool for **data visualization and transformation**. The core data preparation process is handled through **Power Query**, where users can clean, shape, and transform data before analysis.  

#### **Transform Data — Power Query**
- **Query Settings:** Shows the source path of imported data.  
- **Undo Transformation:** Go to *Applied Steps* → Remove the unwanted step.  
- **Row Limitation:** By default, Power BI only shows the first **1,000 rows**.  
  *To work on the entire dataset:* Go to the bottom and select **Column profiling based on entire dataset**.  
- **Make First Row as Heading:** Right-click on the column → *Use first row as headers*.  

## **Power Query — View Options**

#### **Missing Tabs on Dashboard**
- Go to *View* → Select the missing options (e.g., Column quality, Column profile, Column distribution).  

#### **Power Query — View Tab**
- **Column Quality:** Shows data accuracy.  
  - **Valid:** Data is correct and error-free.  
  - **Error:** Indicates format errors.  
  - **Empty:** Shows the number of empty rows.  
- **Column Distribution:** Displays distinct vs unique values.  
  - **Distinct:** Number of different classes.  
  - **Unique:** Classes that occur only once.  
  - If *Distinct = Unique* → No repetition in data.  
- **Column Profile:** Provides full statistics of a column.  

## **Add, Move, Remove - Columns/Rows**

#### **Power Query — Home Tab**
- **Remove Columns:**  
  - *Remove column* → Removes the selected column.  
  - *Remove others* → Keeps only the selected column.  
- **Split Columns:**  
  - *Split by Delimiter* (comma, dash, etc.)  
  - Choose split at: Left / Right / Each occurrence  
  - Advanced options available for customization.  
- **Remove Empty Rows:**  
  - Sort the column → Missing values appear at the top.  
  - *Remove Rows → Remove Blank Rows*.  
- **Handle Duplicates:**  
  - Remove duplicates from the entire dataset → Select table → Remove duplicates.  
  - Remove duplicates from a single column → *Keep rows → Keep duplicate*.  

#### **Power Query — AddColumns Tab**
- **Add Column:**  
  - *Index column* → Assigns index numbers.  
  - Set starting number (e.g., 1, 5) and increment (e.g., 1, 2).
 
#### **Power Query — Transform Tab** 
- **Move Column:**  
  - *Transform → Move → To Beginning* (or other positions).
