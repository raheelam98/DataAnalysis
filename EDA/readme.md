
## ExploratoryDataAnalysis_EDA

Exploratory Data Analysis (EDA) is a critical first step in any data science project. It involves examining and summarizing data sets to understand their main characteristics, identify patterns, detect anomalies, and test hypotheses. EDA helps data scientists uncover hidden insights and make informed decisions about how to further analyze the data

#### **EDA in Data Science**

EDA stands for **Exploratory Data Analysis**.  
It is the process of examining and understanding a dataset before applying machine learning or statistical modeling.  
The goal is to summarize key characteristics, detect patterns, spot anomalies, and check assumptions using statistics and visualizations.  

#### **EDA**

1. **Data Collection & Loading**  
   * Import data from CSV, Excel, databases, APIs, etc.  

2. **Data Cleaning**  
   * Handle missing values, duplicates, inconsistent entries.  
   * Fix data types and column names.  

3. **Univariate Analysis (single variable)**  
   * Numeric → Histogram, KDE, Box Plot  
   * Categorical → Bar Chart, Pie Chart  
   * **Purpose:** Understand the distribution of each variable.  

4. **Bivariate / Multivariate Analysis (relationships)**  
   * Scatter Plots, Heatmaps, Pair Plots  
   * **Purpose:** Identify correlations, trends, and interactions.  

5. **Outlier Detection**  
   * Box Plots, Z-scores, IQR method.  

6. **Feature Engineering (optional)**  
   * Create new variables, group categories, normalize/scale data.  

#### **Common EDA Plots**
* **Histogram** → Distribution of a single variable  
* **KDE Plot** → Smooth distribution curve  
* **Box Plot** → Spread & outliers  
* **Bar Chart** → Compare categories (e.g., gender, product type)  
* **Pie Chart** → Category proportions (e.g., sales share)  
* **Line Chart** → Trends over time (e.g., stock prices, sales growth)  
* **Scatter Plot** → Relationship between 2 numeric variables (e.g., age vs income)  
* **Heatmap** → Correlation between variables  

#### **Why EDA is Important?**
* Helps you understand your data  
* Guides feature selection for models  
* Detects errors, biases, and outliers early  
* Prevents wrong assumptions in analysis  
* Provides business insights before modeling
